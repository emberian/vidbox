# vidbox

Little custom tools for assembling video pieces.

```sh
uv sync
./tools/prep.sh                         # build proxies + face-tracked clip into media/derived/
uv run python studio/server.py          # then open http://127.0.0.1:8765/studio/index.html?project=meine
uv run python projects/meine/comps/full.py       # composition script -> comps/out/full.timeline.json
uv run python render/tl.py projects/meine/comps/out/full.timeline.json --range 60 70 --jobs 3
                                                 # half-size preview next to the timeline; --full for 1:1
```

- `render/`: the timeline renderer. `TIMELINE.md` is the format, `comp.py` the composition DSL the
  scripts in `projects/<name>/comps/` use, `tl.py` the renderer (`VIDBOX_CRF=0` renders
  losslessly, for frame comparisons), `FX_EXTRA.md` the extra effects. `studio/timeline.html`
  views a timeline with its render.
- `render/render.py` is the original project.json renderer from the path-capture studio (one
  background, face layers on Bezier paths); timelines have replaced it for the Meine piece.

- `media/` (gitignored): `src/` originals, `derived/` generated by `tools/prep.sh`.
- `projects/<name>/project.json`: size, fps, duration, background, layers (src, start, size,
  mask, opacity, gain, path). The studio writes opacity/gain changes back here.
- `projects/<name>/paths/*.json`: timed cubic Bezier paths (`anchors`) plus the raw capture
  `takes` they were fitted from. Format documented at the top of `studio/bezier.js`;
  `render/bezier.py` evaluates them identically.
- `studio/`: browser editor (capture, fit, edit) served by `server.py`, which adds HTTP Range
  support for video seeking and a `POST /api/save` limited to `projects/**.json`.
